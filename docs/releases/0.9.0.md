# recordbox 0.9.0

This release brings Adam Sardo’s beat and phrase analysis, EDIT timeline, performance effects and controller work into the fork. Two choices matter when upgrading from 0.8.1. New beat analyses use the Rekordbox-compatible detector, and live STEMS preview is opt-in on supported GPUs. [Upstream integration and measurements](https://github.com/fantuz/recordbox/blob/v0.9.0/docs/UPSTREAM-INTEGRATION.md)

## Preparing tracks and USB drives

- **Beat grids.** New analyses use the Rekordbox-compatible Normal or Dynamic detector. Choose **recordbox classic** under **Preferences → Analysis → Beat grid estimator** to use the earlier detector. High-precision transient refinement works with either. Existing prepared grids change when you choose to reanalyze or edit them.
- **Phrases.** Deck loading and classic USB export can reuse the recorded mood, phrase boundaries, fills and additional ANLZ fields when the source grid matches. For tracks missing phrases, choose an estimator under **Preferences → Analysis → Track Analysis → Phrase estimator**. USB phrase analysis now runs on Linux, limits memory use and reports how many tracks received new phrases if some exceeded its limits.
- **Imported MP3 cues.** If a cue sounds early or late, launch `recordbox --mp3-timeline rekordbox` to compare the same timestamp in a separate collection. In one measured MP3, a click at 1.000 s on the usual clock played at 1.025 s on the trial clock. The offset depends on the file. A normal launch opens your usual collection. [Listening guide for Windows, Linux and macOS](https://github.com/fantuz/recordbox/blob/v0.9.0/docs/PLAYBACK-PERFORMANCE.md#auditioning-rekordbox-mp3-timing)
- **Desktop library sync.** Both directions are legible in light and dark themes. The review shows which library will be read and which will be written before you confirm. [Desktop sync and supported edits](https://github.com/fantuz/recordbox/blob/v0.9.0/docs/LIBRARY-SYNC.md)

## Editing and performing

Use the EDIT timeline to arrange, audition and render a track as WAV, AIFF or FLAC. On macOS you can also render M4A. PERFORMANCE gains more deck layouts, sampler and recorder controls, AutoMix, Mix Point Link, and updates to SPACE, GATE COMP, Beat FX, Pad FX and MERGE FX. MERGE FX can use factory sounds from your own installation.

Groove, Slicer and sampler captures protect existing audio. If two instances save a capture under the same name, each receives its own numbered WAV.

MIDI Learn supports deck, jog, mixer and pad mappings, with LED feedback on supported output ports. Opening the MIDI window preserves the inherited mapping until you edit it. Linux follows a learned controller when ALSA assigns a new client number. Disconnecting a controller releases its held controls. If two inputs have the same mapping identity, the MIDI tooltip identifies the paused inputs. Controller-specific handshakes, HID players and PRO DJ LINK remain outside this MIDI implementation. [Controller and effect coverage](https://github.com/fantuz/recordbox/blob/v0.9.0/docs/UPSTREAM-INTEGRATION.md#controllers-and-effects)

## Previewing STEMS during separation

On eligible Apple Silicon and CUDA 12 hardware, enable **Preferences → Extensions → STEMS → Preview finished sections during new separations** to audition finished sections while the rest of the track is processing. Quality mode makes previews available during the fourth model pass. Vega on DirectML or experimental Linux Vulkan, Quadro P2000 and CPU builds continue to use completed, cached separations. [Hardware requirements and memory limits](https://github.com/fantuz/recordbox/blob/v0.9.0/docs/UPSTREAM-INTEGRATION.md#stems-by-device)

Six native phrase sections round-tripped byte-for-byte in the integration checks. On one 3:31 synthetic track the Linux phrase analyzer produced identical output to upstream while peak process memory fell from 250 to 150 MiB. CPU time rose from 12.16 to 13.09 seconds. Physical-controller latency and listening comparisons across all effect presets still need hardware testing. [Build checks and tracked dependency advisories](https://github.com/fantuz/recordbox/blob/v0.9.0/docs/BUILD-AND-PACKAGING.md)
