# recordbox 0.9.1

This release brings Adam Sardo’s recent beat-grid, effects and export work into the fork. It also fixes whole-collection memory pressure and protects prepared tracks when analysis, device sync or cleanup runs again.

## Preparing a collection

- **Add New Analysis Data** bounds concurrent work by available memory and checks actual decoded length. This addresses an allocation failure observed with a large Windows collection. The worker setting still lets you reserve CPU for playback. [Analysis performance](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/PLAYBACK-PERFORMANCE.md)
- The optional installed beat model can follow changing tempos in sections and repair missed beats where sections meet. It supports eligible tracks up to 15 minutes. Ordinary Rekordbox-compatible and recordbox classic analysis are available on every platform. The library retains the track-wide BPM even when a live intro has a different tempo. [Beat-grid behavior and measured precision](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/UPSTREAM-INTEGRATION.md#what-the-precision-checks-establish)
- The compatible phrase analyzer recognizes additional Low- and Mid-mood arrangements. Existing native phrase data takes priority when preparing USB analysis files.
- Classic USB exports encode the known Rekordbox 7 vocal-level layout in `.2EX` and read it back when refreshing a device. Unrecognized revisions stay intact. Five desktop captures and a known USB byte sequence were used to check this path. [USB formats and evidence](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/USB-COMPATIBILITY.md)
- USB preparation observes Stop and the analysis memory budget. A failed refresh reports the track and can keep an existing device copy. A sync that would remove unreferenced tracks stops before those removals if preparation fails. Cleanup also protects the relationship between an original track and its derived edits or stems. [USB compatibility](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/USB-COMPATIBILITY.md)

## Exporting and performing

- **Export Stems** saves Vocals or Instrumental from a completed deck separation or its matching cache. It can carry cues, ratings, the grid and playlist placement to the new entry. Files use unused names. WAV, FLAC and AIFF preserve lossless audio. MP3 is available on every platform and AAC on macOS. AIFF decoding now stops at the sound chunk, including when artwork or annotations follow the music. [Export workflow](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/UPSTREAM-INTEGRATION.md#exporting-vocals-and-instrumentals)
- Beat FX gains revised echoes, modulation, stretch, reverb and vinyl brake. MERGE FX smooths clip restarts and the master meter shows peaks before limiting. In a Linux CPU test several echoes became cheaper to process, while the revised reverb and stretch used more time. [Effect measurements](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/UPSTREAM-INTEGRATION.md#effect-selection-and-playback-cost)
- In **PERFORMANCE → MIDI**, select the primary **OPUS-QUAD** input and choose **Try OPUS-QUAD profile**. The session-only profile maps four decks and 12 PLAY, CUE and JOG MODE lamps. Software replay covers the published messages. Physical jog calibration, lamps and audio routing still need hardware validation. The standalone player requires a OneLibrary USB catalog. [Setup and hardware checks](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/studies/OPUS-QUAD.md)
- Reassigning a held MIDI control releases its action on the original deck. EXPORT and PERFORMANCE also gain a Light appearance, including the detachable browser and library-sync dialogs.
- **Interface motion** adds visible hover, press, selection and drop feedback. Choose Full, Reduced or Off in **Preferences → Advanced → Others → recordbox**. Scrolling loads album covers in the background. Waveform drawing follows the playback frame-rate setting and hardware fader feedback remains immediate. [UI behavior and measurements](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/UPSTREAM-INTEGRATION.md#interface-motion-from-ef454ed)
- With the library detached, F11 toggles both windows. An explicit F11 assignment in the active custom keyboard mapping takes precedence. Closing the library window redocks it, including while a desktop write-back is running. The main window waits for an active write or recovery to finish before it can close.
- Playlist drag-and-drop now uses the visible portion of each row. Releasing a track on the fixed toolbar above a scrolled playlist tree leaves the playlists alone.
- Compatible controller mappings can drive additional Key Shift, Active Censor, Beat Jump, sampler-bank and effect controls. The importer recognizes 172 more function names. Fifty appear in MIDI Learn and 122 are aliases used by factory maps. Shifted pads share the corresponding on-screen action and feedback. Switching to a two-deck view releases holds on the parked decks.

The Windows DirectML, experimental Linux Vulkan and optional CUDA 12 builds retain their device-specific memory limits, model selection and reusable STEMS cache. [Hardware guide](https://github.com/fantuz/recordbox/blob/v0.9.1/docs/UPSTREAM-INTEGRATION.md#stems-by-device)
